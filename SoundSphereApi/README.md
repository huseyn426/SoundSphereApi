# SoundSphere - Modern Music Streaming Platform

SoundSphere is a premium, music-first streaming platform built with ASP.NET Core MVC and Vanilla JavaScript. It features a stunning dark theme, real-time player, and seamless multi-language support.

## ✨ Features

- **Dynamic Localization**: Instant RU/EN switching without page reloads using a custom client-side engine.
- **Real-time Player**: Advanced audio controls including Queue, Shuffle, Repeat, and Volume.
- **Global Search**: Categorized live search for Tracks, Artists, and Playlists.
- **Admin Dashboard**: Full control over users, tracks, and the music catalog.
- **Social Features**: Likes, comments, and listening history tracking.
- **PWA Support**: Installable application with offline caching capabilities.
- **Responsive Design**: Premium dark aesthetics inspired by industry leaders.

## 🚀 Tech Stack

- **Backend**: ASP.NET Core MVC 8.0, Entity Framework Core.
- **Frontend**: HTML5, Vanilla CSS3 (Custom Design System), Vanilla JavaScript.
- **Database**: Microsoft SQL Server.
- **Authentication**: JWT & Session-based security.

## 🛠️ Getting Started

1. Clone the repository.
2. Update the connection string in `appsettings.json`.
3. Run `dotnet ef database update`.
4. Start the application with `dotnet run`.
5. Access the app at `https://localhost:7148`.
